# Backend API

A RESTful Backend API built using FastAPI for managing Projects and Tasks.

## Features

- Create a project
- Get all projects
- Create a task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task
- Task status validation

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
