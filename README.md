# Productivity Dashboard

A responsive productivity dashboard built with React and Vite to help users manage daily tasks and track their productivity.

## Features

- Add and manage tasks
- Mark tasks as completed
- Task filtering
- Responsive user interface
- Modern dashboard design

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- HTML

## Installation

1. Clone the repository
2. Install dependencies:
   npm install
3. Run the project:
   npm run dev
